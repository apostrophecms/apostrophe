The MCP server (`@apostrophecms/mcp`) adds two tools for the media library. `save_image_to_media` adds an image from base64 data, with a title and alt text, and returns its id for use in widgets. The image is published at once. On a site with several locales, it also takes `locale`. `get_image` returns an image's title, alt text, dimensions and file type, and a full link to each of the project's image sizes (the attachment module's `imageSizes`) with that size's dimensions, smallest first. It never returns the image's data. Only the MCP server offers these tools. An image goes through the same intake as an upload, with the same allowed file types and SVG sanitizing, and a file that isn't an image is refused before it is stored. The new `maxImageSize` option limits an image's size, and is 10 MB by default. Images arrive as base64 in JSON, and the JSON body limit is 16 MB, so a limit over about 12 MB also needs `bodyParser.json.limit` raised on `@apostrophecms/express`.
