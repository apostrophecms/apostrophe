Adds an MCP server, `@apostrophecms/mcp`, so outside AI tools such as Claude, ChatGPT or an AI assistant in an IDE can work on a site's content for a user. The user approves a tool once on the site and can disconnect it at any time. A connected tool can do only what that user may do, and it brings its own AI model, so it never spends the site's AI budget. It saves every change as a draft, marked as made by AI and recorded in a change log, and it can't overwrite edits made after it read a document. It can also add images to the media library and, when the user may, publish. The server is off until it is enabled.
